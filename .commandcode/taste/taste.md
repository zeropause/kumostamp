# Taste

## Communication & Problem Solving
- Pushes back when told something is impossible; expects the agent to research/probe for a workaround instead of accepting "not supported" as the answer. Confidence: 0.55

## UI & UX
- In user-facing surfaces (cards, links, previews), point clicks at the real external source/content provider rather than back into the app itself — don't let the UI double as an ad for the app. Confidence: 0.6

## Git & Commits
- Never add a `Co-authored-by` trailer (or any assistant attribution) to commits or PRs; repeat instruction across many pushes makes this a standing rule. Confidence: 0.95
